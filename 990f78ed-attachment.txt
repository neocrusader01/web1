# TASK: Build a Premium Cinematic Two-Tier Birthday Cake Animation

Create a **single, self-contained HTML file** containing everything required for the experience:

- HTML
- CSS
- Vanilla JavaScript
- Inline SVG and/or Canvas

Do **not** split the project into multiple files.

The final output must be a polished, cinematic, premium birthday-cake animation that visually shows a **realistic TWO-TIER birthday cake being constructed from individual ingredients and components, one step at a time**.

The experience should feel like a miniature cinematic cake-making scene rather than a flat website animation.

---

The page must show **ONLY the birthday-cake scene**.

Do NOT create:

- Navigation bars
- Headers
- Footers
- Hero sections
- Cards
- Sidebars
- Landing-page sections
- Text menus
- Large UI panels
- Unrelated decorative sections

The entire viewport is the scene.

Use:

```css
html,
body {
    width: 100%;
    height: 100%;
    margin: 0;
    overflow: hidden;
}
```

# 9. IMPORTANT ANIMATION RULE

The cake must be constructed **STRICTLY SEQUENTIALLY**.

This is extremely important.

Only one major construction action should happen at a time.

The viewer must clearly understand:

> component → placement → completion → next component

Do NOT show the complete cake at the beginning.

Do NOT reveal future components prematurely.

Do NOT animate all ingredients simultaneously.

Every major step must complete before the next major step begins.

Use a timeline/state-machine architecture rather than a collection of unrelated CSS animations.

For example:

```javascript
const steps = [
    buildCakeBoard,
    buildBottomSponge1,
    addBottomFilling,
    addBottomSponge2,
    frostBottomTier,
    addBottomGanache,
    addDowels,
    buildTopTier,
    addDecorations,
    addToppings,
    addCandles,
    lightCandles,
    celebration
];
```

Each function should return a Promise so the next step waits for completion.

Example concept:

```javascript
async function runSequence() {
    await buildCakeBoard();
    await buildBottomTier();
    await addFrosting();
    await addCandles();
    await lightCandles();
    await celebration();
}
```

Do not start the next major stage until the previous stage has finished.

# 10. STEP 1 — CAKE BOARD

Start with an completely empty table.

After a short cinematic pause:

A round metallic cake board enters the scene.

The board should:

- slide gently into the center
- slightly rotate while entering
- settle naturally
- have a subtle bounce
- cast a soft shadow

Use:

- gold or champagne metallic edge
- slightly darker center
- subtle radial highlight

After placement, create a light sweep across the board.

The shine should travel from left to right.

Pause briefly.

---

# 11. STEP 2 — FIRST BOTTOM SPONGE

A thick round chocolate sponge layer enters from above.

The sponge should:

- descend naturally
- accelerate slightly
- slow down before landing
- land on the cake board
- compress slightly
- bounce once
- settle

Use subtle squash-and-stretch.

Do NOT make it bounce like a rubber ball.

The side of the sponge must contain visible texture.

Create small:

- air pockets
- pores
- irregular baked texture

The top should be slightly lighter.

The side should be darker.

Add a subtle shadow underneath.

---

# 12. STEP 3 — BOTTOM FILLING

A piping bag enters from above/side.

The piping bag must feel like an actual baking tool.

It should:

1. move into position
2. touch the cake
3. squeeze
4. dispense cream
5. move in a circular spiral
6. cover the sponge
7. stop squeezing
8. move away
9. fade/exit

The cream should visibly grow from the center outward.

Do not simply fade in a white circle.

The filling must look like it is being physically deposited.

Then add strawberry slices.

Strawberries should:

- appear individually
- drop onto the cream
- slightly rotate
- bounce gently
- settle naturally

Use approximately 4–6 slices.

Each slice should have:

- red/pink body
- lighter inner flesh
- tiny seed details

Pause after the last strawberry.

---

# 13. STEP 4 — SECOND BOTTOM SPONGE

A second chocolate sponge layer enters from above.

It should align with the first layer.

The layer should:

- descend
- slow down
- touch the filling
- compress the cream slightly
- create a tiny cream bulge around the edge
- bounce gently
- settle

The filling should remain visible slightly around the edge.

Do not completely hide the filling.

---

# 14. STEP 5 — BOTTOM TIER FROSTING

Now introduce a cake spatula/palette knife.

The spatula should:

1. enter from the side
2. approach the cake
3. begin spreading frosting
4. move around the circumference
5. smooth the sides
6. smooth the top
7. perform a final finishing pass

Create a believable frosting-wrap animation.

Use:

- cream/white buttercream
- subtle pastel warmth
- darker shading at the bottom
- brighter highlights on the upper edges

Add a glossy highlight after the final smoothing pass.

The completed tier should look like a professionally frosted cake.

# 15. STEP 6 — CHOCOLATE GANACHE DRIP

# 37. PERFORMANCE

Target smooth animation.

Use:

```javascript
requestAnimationFrame()
```

for continuous effects.

Avoid unnecessarily creating hundreds of DOM elements.

Prefer:

- SVG groups
- Canvas particle systems
- CSS transforms
- opacity
- GPU-friendly transforms

Avoid expensive layout-triggering animations such as repeatedly changing:

```javascript
top
left
width
height
```

during high-frequency animation.

Prefer:

```css
transform: translate(...)
transform: scale(...)
transform: rotate(...)
opacity
```

Use `will-change` only where appropriate.
